# Rare Character Classes

When a loved character dies, the Referee may offer the player to either make a new character using the regular rules, or make a character in one of the *rare classes*: the Brave, the Clever and the Fortunate. Each plays differently and may open up new and fresh ideas for the player. In some campaigns, it can be better to swap a regular class for a rare one. For example, in a campaign with lowkey magick, perhaps the Wise should be rare and the Clever should be regular?
