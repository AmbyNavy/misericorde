# Monster Table Entries

- **DF:** This is the monster’s defense with standard armor factored in. For example, a dwarf has DF 5 because she is expected to use protection equivalent to a shield and a chainmail. If you want to equip a humanoid differently, you would start at DF 0 unless there is natural armor involved. See the chapters on character generation (p. 44) and core rules (p. 56) for more information on DF.
- **HD:** This is the number of harm dice (d6) used to determine a creature’s harm points. If there is a positive modification, you apply it *once only*. If there is a given range, you choose any HD within that range. For example, the HD 4+7 Frost Giant means that you would roll 4 harm dice and then add another 7 HP. “1 HP” means HD 1, but the creature has a single harm point.
- **MV:** This number is the monster’s movement rate. It is handled just like movement rates for characters, except the expected encumbrance has already been factored in. If there are alternatives, like 25/40, it means that the creature has multiple ways of moving. The first number is its land movement, the second its water or air movement (which should be self-explanatory for the particular creature). When a monster picks up something heavy, you can change MV.
- **LT:** This entry, together with monster HD, configures a loot roll (p. 121), sometimes used by the Referee.

## Monster Keywords

Keywords can be used as characteristics (immunities, traits, abilities etc.), as miracle wordings or as abilities that you either script in advance or improvise on the fly. As a rule of thumb, all non-human creatures can see better in the dark than humans. This is not listed in the tables.

- For miracles and abilities alike, a good idea is to have the monster pay a few hp. This lessens the impact of any accidentally overpowered keyword uses. 
- Remember also that a monster who has “Acidic,” “Paralyze” or something else listed doesn’t have to be exactly the same as another member of its species. It is all right to interpret the keywords differently for two individuals—it provides variation and keeps your players on their toes!
