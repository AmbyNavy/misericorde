# Appendix

## Tomb of Tunka Jinn

Everything in the book is intended for players as well as Referees, which means that the Referee must take the last steps towards a finished beginner adventure herself: 
1. The adventure is called “Tomb of Tunka Jinn.” It follows the phase map on p. 101. Begin by fleshing the phases out with a few sentences each. 
2. The structure of the *false* tomb has already been drawn (p. 103). Translate it to an actual (boring) map, and place instructions or a key somewhere, for how to get to the true *tomb*. Add a standard monster if you like. 
3. Using the instructions on map design, draw the true tomb as a more complex and interesting dungeon. Pick a base monster to inhabit it. 
4. Spice that base monster up, like was done to the orc on p. 123. 
5. Using the instructions found on p. 104, replace the three factions (modifying relations) in the triangle mind map. You can use player character affiliations if they fit, but if they don’t, make sure at least one of the factions has an interest in the tomb of Tunka Jinn. 
6. Create three events (p. 105) that can trigger at least two of the factions. 
7. Create a lesser boss monster. Pick a standard monster from the table and spice it up a bit. Then turn the result into a boss, following the boss rules (p. 122), and give it an extra stage. If unsure, look at the example boss on p. 126. If you want the boss to be capable of partitioning, make a few notes on this as well. 
8. Using the Magick Item Concepts list (p. 127), add a secondary treasure to the true tomb, as well as some valuables. Use quest XP to double the amount earned from killing monsters and acquiring treasure.

This is enough to give you a solid adventure, but you can of course work more on it if you want. Don’t forget to roll for Referee input (p. 107) if you get stuck! You can also use the below questions:

- Who was Tunka Jinn? 
- Why is there both a false tomb and a true tomb? 
- Where can they be found? 
- What do Tunka Jinn’s relics do? 
- Who are the competition? 
- Are they hired by one of the factions? 
- Where do the characters get the mission, and where will they rest and spend their loot?

## A Setting Will Grow 

Unless you want to or have one in mind, you don’t need to worry about setting at this point. You can assume that it is something based on the opposite pairs on p. 96. The first step towards something more developed would then be to try to think of some catalyst event creating the opposites and the tension between them. Why don’t you play the adventure, and then involve the group in coming up with some preliminary ideas?

## Building Setting with Macros

Optionally, you can boost the collective setting building process by using macros (p. 114).

- Have a macro phase (p. 115) after each session.
- Create some macros for **very** major things, like “The Planet,” “The First Civilization,” “Literature,” “Religion” and “Technology.”
- During each macro phase, agree on a historic period, beginning with some important event based on one or several opposite pairs. Distribute the macros and have them react and chain-react. 
- Make new macros and discard old ones as you go along. Usually, this process means that the macros branch off from being extremely general to more specialized and colorful. For example, “Religion” might turn into macros for two separate forms of belief. 
- Continue this process until you reach a historic point right before the current era of the game world. Then start using the macro phase for things that are more directly relevant to your campaign.
