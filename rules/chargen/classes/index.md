# Characters
## Using the Character Class Tables 
In the following sections are descriptions and tables for the Deft, the Strong and the Wise character classes. The optional rare classes are to be found in a later chapter (p. 80). 

Each level requires an amount of XP. HD is the number of harm dice you roll, hoping to increase the character’s HP. **You roll all HD at each new level**, using the new total if it is better than the old HP score. Note the attack and save values (AV and SV) on the character sheet. Slots are for some of the class abilities, and groups are how many groups the character can belong to in a mechanical sense (p. 41). Raises give the character an extra attribute point, freely allocated, at even levels (the rare Brave class can also choose to reduce an attribute one point instead). 

To generate a higher level character, step through the levels and re-roll hd for each of them as per above. Also take 100 extra crowns for each level above the first, to buy extra equipment (p. 44). The Referee may award magick items if she feels that it is appropriate for a higher level character to have them.
